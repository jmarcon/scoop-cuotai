# Scoop bucket for Cuotai

Install [Cuotai](https://github.com/jmarcon/cuotai), the monitor for AI usage limits, quotas and costs, on Windows:

```powershell
scoop bucket add cuotai https://github.com/jmarcon/scoop-cuotai
scoop install cuotai/cuotai
```

`bucket/cuotai.json` is generated and updated by the Cuotai release pipeline from each verified GitHub Release. Do not edit it by hand; report problems at https://github.com/jmarcon/cuotai/issues.
